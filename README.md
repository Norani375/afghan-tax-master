# محاسبه مالیات افغانستان 🏛️

Afghan Tax Calculator - Tax settlement web app based on Afghanistan Income Tax Law.

## Setup
1. Clone the repo
2. `npm install`
3. Create `.env.local` with your Neon DATABASE_URL
4. `npm run dev`

## Deploy to Vercel
1. Push to GitHub
2. Import in Vercel
3. Add DATABASE_URL environment variable
4. Deploy!
